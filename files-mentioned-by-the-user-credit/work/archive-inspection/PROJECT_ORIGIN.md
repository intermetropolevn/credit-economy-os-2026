# Project Origin

**Project:** Credit Economy OS  
**Purpose:** Explore an AI-native economic control plane for programmable value.  
**Maintainer:** Intermetropole  
**Repository:** https://github.com/intermetropolevn

The project began as an AI-assisted prototype and has been refactored for public review as a hackathon demonstration. It uses simulated economic data and does not represent a production financial service or a live integration with the organizations shown in the interface.
