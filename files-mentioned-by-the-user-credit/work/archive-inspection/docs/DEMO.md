# Demo walkthrough

1. Start the app with `npm run dev` and open `http://localhost:3000`.
2. The Dashboard summarizes circulating credits, settlement status, and demo intelligence.
3. Open the highlighted transaction or use the guided demo bar.
4. Run AI verification. In default mode this is a deterministic, validated proposal.
5. Review the observation, recommendation, risk, evidence, and authorization state.
6. Approve settlement to demonstrate the human governance gate and ledger update.
7. Browse Pools, Rewards, Experiences, Analytics, and AI & Integrations for the broader simulated system.

Use Reset in the demo bar to restore the original in-memory state.
